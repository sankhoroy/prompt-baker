# prompt-baker examples

These examples assume you have installed **prompt-baker** (from PyPI or editable from the repo root). They use **additional** libraries (LangChain, Groq, Chroma, and so on) that are not core dependencies of `prompt-baker`; install them in the same environment before running.

Install the base package from the repository root:

```bash
cd /path/to/prompt-baker
uv sync
# or: pip install -e .
```

---

## 1) Sentiment classification (`examples/sentiment/`)

**Script:** [`run_sentiment_optimisation.py`](sentiment/run_sentiment_optimisation.py)

**Notebook:** [`sentiment_classification.ipynb`](sentiment/sentiment_classification.ipynb)

**Data:** [`benchmark_sentiment.csv`](sentiment/benchmark_sentiment.csv)

What it does:

- Loads a sentiment benchmark CSV (`input` / `target`).
- Defines one or more completion backends (e.g. a word-count heuristic and optionally a Groq-backed LangChain agent).
- Runs the genetic optimizer for **classification** with a metric such as `accuracy`.
- Writes logs under `examples/sentiment/logs/run_*` (relative to the script’s `run_dir` setting).

**Run (from repo root):**

```bash
uv run python examples/sentiment/run_sentiment_optimisation.py
```

If you use the Groq path, set `GROQ_API_KEY` in the environment and avoid committing real keys in the script.

**Optional:** plot optimization progression for a finished run:

```bash
uv run python scripts/visualize_logs.py --run-dir examples/sentiment/logs/run_YYYYMMDD_HHMMSS
```

The script may also call `plot_progress` on the optimizer’s run directory directly.

**Typical extra installs** (versions may vary):

```bash
uv pip install langchain-groq langchain langgraph
```

## 2) Cat–dog RAG (`examples/rag_cat_dog/`)

**Script:** [`cat_dog_rag.py`](rag_cat_dog/cat_dog_rag.py)

**Notebook:** [`cat_dog_rag.ipynb`](rag_cat_dog/cat_dog_rag.ipynb)

What it does:

- Creates or refreshes `knowledge_base.txt` and `benchmark.csv` in the **current working directory** (the script uses relative paths).
- Builds a Chroma vector store over the knowledge base with HuggingFace embeddings.
- Registers several retriever strategies (similarity and MMR, different `k`) as separate `ChatModelSpec` entries.
- Optimizes **generation** with `llm_as_judge`, plus paraphrasing and judge hooks backed by Groq.
- Writes logs (see `run_dir` inside the script, e.g. `logs_cat_dog_rag_run2`) and can emit `generated_report_*.csv` via `create_scores_csv`.

**Run from the example directory.** The script writes `knowledge_base.txt`, `benchmark.csv`, and Chroma data relative to the **process working directory**, so start here:

```bash
cd examples/rag_cat_dog
uv run python cat_dog_rag.py
```

From the repository root in one line:

```bash
cd examples/rag_cat_dog && uv run python cat_dog_rag.py
```

Set `GROQ_API_KEY` for the LLM and judge paths.

**Typical extra installs** (versions may vary):

```bash
uv pip install langchain langchain-core langchain-text-splitters langchain-chroma \
  langchain-groq langchain-huggingface chromadb sentence-transformers
```

### Cat–dog RAG with custom embedding metric (override)

**Script:** [`cat_dog_rag_embedding_similarity.py`](rag_cat_dog/cat_dog_rag_embedding_similarity.py)

Same Chroma + Groq RAG setup as above, but the score is **`embedding_similarity`**, using a **custom** SentenceTransformer chosen via `PROMPT_BAKER_EMBEDDING_MODEL` (default `sentence-transformers/all-mpnet-base-v2`). The script replaces `embedding_similarity_metric` on the `prompt_baker.optimizer` module so the library source tree does not need edits.

```bash
cd examples/rag_cat_dog
PROMPT_BAKER_EMBEDDING_MODEL=sentence-transformers/all-mpnet-base-v2 uv run python cat_dog_rag_embedding_similarity.py
```
